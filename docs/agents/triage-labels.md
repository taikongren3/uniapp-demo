# 分诊标签

这些技能使用五种标准分诊角色。下表将这些角色映射到本仓库 Issue 跟踪平台中实际使用的标签名称。

| mattpocock/skills 中的标签 | 本仓库实际标签        | 含义                         |
| -------------------------- | --------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`        | 需要维护者评估此 Issue        |
| `needs-info`               | `needs-info`          | 等待报告者补充更多信息         |
| `ready-for-agent`          | `ready-for-agent`     | 规格完整，可交由智能体处理     |
| `ready-for-human`          | `ready-for-human`     | 需要人工实现                  |
| `wontfix`                  | `wontfix`             | 不会处理                     |

当技能提到某个角色时，使用表中对应的实际标签名称。

如需匹配现有标签体系，请编辑中间一列。
